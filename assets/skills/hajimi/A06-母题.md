## 第 2 阶：12 大脱敏世界观基建母题 $\times$ 5 级聚落尺度索引库

*(注：所有母题均支持自由切换 `Track_A 90°垂直正射` 或 `Track_B 高空立体鸟瞰`，并强制执行真实比例尺与有机街廓)*

1. **`M01: 高压管网与重工锅炉基建`**：环形锅炉大院核心 + 架空保温蒸汽管网动脉 + 锯齿天窗厂房与联排工人坡屋顶街廓。（`都会 / 机车转盘镇 / 露天矿坑村 / 管道荒原 / 锅炉室内平面`）
2. **`M02: 迷雾河港与地下遗迹产业基建`**：S型潮汐黑水河与分支运河 + 蛛网状中世纪毛细暗巷与空心天井街廓 + 内嵌大学/教堂围合院落与梳齿船坞。（`运河港都 / 发掘坑古董镇 / 高脚屋渔村 / 礁石灯塔 / 洋馆地宫平面`）
3. **`M03: 坠落星舰残骸与垂直峡谷基建`**：十公里弧形装甲舰体屋脊 + 寄生于峡谷岩壁的数千微缩集装箱街块与跨渊管道桥。（`星舰峡谷城 / 换气竖井镇 / 拾荒帐篷村 / 机甲坟场 / 倾斜舰舱平面`）
4. **`M04: 移动陆行装甲舰与防灾扇区基建`**：重型履带钢铁底盘 + 防灾隔离槽切割的高密机能街块、停机坪矩阵与中央舰桥院落。（`移动城邦 / 采矿平台镇 / 装甲游牧营 / 黑晶荒原 / 防爆收容所平面`）
5. **`M05: 多层立体天桥与巨企金字塔基建`**：高密摩天楼屋顶切面（停机坪/冷却塔/天井） + 跨街谷多层高架路网 + 底层幽暗排污街巷。（`立体摩天城 / 自动港镇 / 断桥幸存村 / 太阳镜阵荒原 / 义体机房平面`）
6. **`M06: 同心圆星形棱堡与圣堂基建`**：几何折线沃邦式星形火炮棱堡外墙 + 内部自然生长的曲折红瓦围合街廓 + 放射大道汇向中央圣堂院落。（`棱堡王都 / 双塔桥镇 / 风车农耕村 / 关隘山口 / 圣堂王陵平面`）
7. **`M07: 垂直深渊迷宫巨坑与冒险产业基建`**：中央圆形地质深渊巨坑 + 顺应等高线蛛网状层层环绕的铁匠坊、交易所与环形阶梯街区。（`深渊环城 / 百炉锻造镇 / 巨树冠层村 / 发光菌林 / 机关石室平面`）
8. **`M08: 现代海岸网格与学园岛铁道基建`**：防波堤港湾、高架电车弧线、体育场椭圆切面与数千栋现代建筑屋顶织体。（`跨海学园都 / 海岸坡道镇 / 离岛码头村 / 盘山天文台 / 教学楼医院平面`）
9. **`M09: 华夏礼制坊市与山水悬崖基建`**：棋盘格里坊大街内嵌数百座三进四合院灰瓦矩阵 + 蜿蜒江南水系、石拱桥与荷池园林。（`中轴里坊皇城 / 百桥水乡古镇 / 梯田土楼村 / 绝壁剑冢 / 王府地宫平面`）
10. **`M10: 和风城下町、护城河石垣与鸟居山林基建`**：折线巨石城垣与护城河 + 短册状前店后院木造町屋密集屋顶簇 + 后山杉林朱红鸟居参道。（`城下町主城 / 温泉长街镇 / 合掌造雪村 / 竹林参道 / 枯山水宅邸平面`）
11. **`M11: 极地地热融冰深井与沙海绿洲基建`**：围绕圆形地热井或蓄水漏斗呈同心扇形紧密抱团的坡顶/平顶石屋簇与放射状明渠管网。（`融冰深坑城 / 破冰船科考镇 / 鲸骨帐篷村 / 冰缝迷宫 / 温室钻井平面`）
12. **`M12: 深海耐压穹顶与云海浮空群岛基建`**：铁索桥与船坞栈桥相连的多块不规则浮空岛（或深海玻璃穹顶群），岛面布满顺应崖边生长的围合街块。（`浮空群岛都 / 飞空艇船坞镇 / 珊瑚礁水下村 / 浮石光桥 / 水密舱平面`）

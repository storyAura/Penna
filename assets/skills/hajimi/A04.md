# 二次元抽卡手游精英化2（精二）立绘导演系统 (v4.5 去眼球化焦点重构 & 万物拟人版)

本技能是专门用于构思与编译二次元抽卡手游角色**“精英二化 / 觉醒”立绘（Elite 2 Splash Art）**以及**“万物概念/历史/体育传奇/城市拟人娘化立绘”**的高内聚单文件总控中枢。它作为 `cg-art-director-system` 的 **`Tier C+ (Elite2_Island_Splash)`** 专项覆写层，直接联动 `moss-image-prompt-enhancer` 输出自然语言 Caption 或中心化像素坐标 Layout JSON。

## 零、 三大绝对创作红线 (Three Absolute Creative Redlines)

Agent 在执行任何精二立绘或万物拟人推演与编译时，**必须默认死守以下三条铁律（除非用户在指令中显式要求打破）**：

1. **【红线一：默认禁绝动物/怪物 + 默认禁绝背景巨型眼球法则 (Zero Unrequested Creatures & Zero Giant Eyeballs)】**
   * **禁绝生物**：除非用户明确要求，画面中绝对不允许出现任何动物、宠物、怪物、巨龙、伴生兽或克苏鲁触手。
   * **禁绝背景巨眼/眼球（`Ocular_Motif = OFF` 默认锁死）**：**在未获得用户明确认可前，绝对禁止在背景、漩涡中心或建筑上生成任何具象的“巨大眼睛、解剖学眼球、瞳孔或凝视之眼符号”！**
   * **【MOSS 潜空间防误触铁律】**：在编写英文 Prompt 时，**严禁使用 `"Eye-of-the-Storm"`、`"iris"`、`"pupil"`、`"ocular"` 等带 `eye` 词根的词汇描述背景净空区**（AI 模型会将 `"Eye-of-the-Storm"` 字面误读并在角色脑后画出一颗恐怖大眼球）。必须统一使用 **`Tonal Contrast Backdrop Core`（明暗反差衬底核）** 或 **`Unobstructed Sanctuary Zone`（无干扰净空区）**。
   * *(可选项协商机制：仅当角色设定涉及“全知视界、精神窥视、克苏鲁盲目痴愚”等极特殊母题时，Agent 可在蓝图中向用户询问：“此处是否需要启用可选的【背景凝视之眼】构图？”，未获批准前一律使用非眼替代方案。)*
2. **【红线二：1:1 真实/宏大尺度场景切片，禁绝“微观场景”与“3D照片背景割裂” (Full-Scale Cutout & Unified 2D Style)】**
   * **严禁微观小人国感**：孤岛立绘的场景绝对不是“玩具微缩模型（Miniature Diorama）”，而是**从真实 1:1 人体尺度或宏大巨物尺度空间中切取出来的一块局部真实舞台切片（Full-Scale Spatial Stage Cutout）**。
   * **角色与场景 2D 画风绝对统一**：场景切片的建筑、病房走廊、球馆看台、岩石与流体，**必须强制加上 `2D hand-painted anime background art (Bijutsu), flat cel-shaded architectural planes, crisp 2D structural linework`**，严禁背景退化为模糊的 3D 渲染图或写实照片景深。
3. **【红线三：大画布套中画布的纯白孤岛边界 (Centered Island in Stark-White Void)】**
   * 所有角色、1:1 场景切片与光影流体，必须严格收敛于大画布中央的**“中画布（Inner Island）”**内，外围四周 $15\%–25\%$ 必须是绝对干净的纯白色虚空（`#FFFFFF`），严禁任何元素触碰大画布四边。

## 第 0 阶：故事感核心引擎——视线方向、大形偏重与光影情绪叙事 (Narrative & Gaze Mechanics)

精二立绘的最高境界是**“一眼入戏的故事感”**。角色绝不一定死板地看向镜头（Camera），而是通过**画外视线引导（Off-Screen Gaze）、大形重心偏移、明暗光影切割与冷暖色彩对撞**，让观众脑补出画面之外的宏大历史与命运余韵。

## 第 0.5 阶：万物概念拟人 / 历史娘化转译引擎 (Concept & Historical Anthropomorphism Engine)

当用户输入**一个具体物品/道具/化学物质（如：吗啡）、一位历史或现代传奇人物（如：拿破仑、科比/黑曼巴）、或一座城市/一段文明历史（如：君士坦丁堡）**要求设计精二立绘时，Agent 必须执行**“三层解构转译律（3-Layer Anthropomorphic Translation）”**：

1. **第一层：物理/文化基因 $\rightarrow$ 映射至 `[2] 20% 觉醒角色本体设计 (Character Design)`**
   * 将器物材质（玻璃安瓿、银针、紫金球衣、大理石金缮裂纹）、历史人物的标志性战袍与体态转化为发色、瞳色与二次元高定服饰。
2. **第二层：历史高光与宿命纪元 $\rightarrow$ 映射至 `[7] 70% 1:1 真实尺度 2D 场景舞台切片 (1:1 Stage Cutout)`**
   * 将该事物最辉煌的主场与最深刻的宿命代价同框压缩进一块 **1:1 真实人体尺度的 2D 手绘建筑/自然切片**中（严禁 3D 照片级写实背景，强制保持 2D 动画美术笔触）。
3. **第三层：核心效用与精神余韵 $\rightarrow$ 映射至 `[1] 10% 信物/贯穿线` + `[O] 无眼球焦点衬底核` + `[G01-G06] 视线与光影`**

## 第 2 阶：精二中画布内的 $7:2:1$ 叙事体块重构 ($7:2:1$ Mass Hierarchy Inside Inner Canvas)

* **`7` — 1:1 舞台切片与历史/概念非生物大形（占中画布 $60\%–70\%$ 面积）**：
  * **严禁微观、生物与野生眼球**：必须呈现与角色 1:1 匹配的真实空间透视感，且完全采用 **2D 动漫背景美术手绘笔触（2D Anime Bijutsu Style）**。
  * **边缘消融铁律（Edge Dissolution）**：到达中画布边界时，通过对应母题的 2D 消融介质自然隐入纯白背景。
* **`2` — 觉醒态/拟人化角色本体与画外视线（占中画布 $15\%–25\%$ 面积）**：
  * 明确锁定角色视线（`G01-G06`），并在视线前方留出充足的**视线呼吸空间（Lead Room）**。
* **`1` — 考据故事信物与高能贯穿线（占中画布 $10\%$ 面积）**：
  * 放置 $1–2$ 个点明拟人原型身份的无生物硬核信物 + 一道刺穿中画布构图的锐利光线/轨迹线。

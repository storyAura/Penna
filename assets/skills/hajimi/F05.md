# 04 Prompt & Layout Compiler (提示词降噪语法、权重封装与坐标编译库)

本模块负责将前 3 阶的美术导演蓝图，转化为 AI 模型潜空间能够 100% 准确执行的**正向提示词（Positive Prompt）**或**MOSS-Image 像素坐标 JSON**。
## 一、 AI 潜空间三大转译铁律

### 1. 正向材质降噪铁律 (Positive Material Occupation)
* **底层缺陷**：扩散模型对正向 Prompt 中的否定词（如 `no clutter, without small leaves, empty`）极不敏感，甚至会因为识别到名词而反向画出杂物。
* **编译规则**：必须用**具象、连贯、低频的物理材质词**去强行占领留白区与暗部画框：
  * ❌ 错误写法：`clean background without messy trees, empty right side`
  * ✅ 正确写法：`an expansive unobstructed pale-cyan sky arch occupying the right half, calm mirror-like dark water surface, unified monolithic obsidian shadow block framing the left edge`

### 2. 距离绑定的细节衰减律 (Distance-Bound Detail Decay)
* **底层缺陷**：一旦在 Prompt 中写入 `intricate details, ultra-detailed`，AI 默认会在前景草叶、中景主体和远景云层上无差别狂刷高频噪点（导致墓地反例）。
* **编译规则**：将细节形容词与空间层级严格绑定：
  * **前景（Foreground）**：绑定 `silhouette, monolithic, unified deep shadow, low-detail framing`
  * **中景锚点（Midground Anchor）**：绑定 `intricate, crisp structural edges, hyper-detailed focal cluster, sharp terminator`
  * **远景与留白（Background & Void）**：绑定 `soft-edged, atmospheric haze, washed-out low contrast, smooth gradient`

### 3. 六段式黄金权重语序 (Six-Slot Token Ordering)
AI 对靠前的 Token 赋予更高的构图权重，对置底的 Token 赋予全局渲染滤镜权重。所有生成的英文 Positive Prompt 必须严格按以下 6 个槽位顺序拼接：

```text
[Slot 1: 镜头机位 + 7:2:1 整体大型剪影骨架]
+ [Slot 2: 前景压暗画框 (Repoussoir) + 实体遮挡关系]
+ [Slot 3: 中景核心主体 + 长短疏密节奏 + 明暗二分与交界线边缘控制]
+ [Slot 4: 视觉锚点高对比锁定 + 紧邻的大块留白载体 + 次级焦点]
+ [Slot 5: 远景大气雾化推远 + 60-30-10 色彩配比与冷暖极性]
+ [Slot 6: 画风固定尾缀 + 线稿/笔触质感 + 置底画质词 (masterpiece, best quality 等)]
```

## 二、 通用防翻车负面词底座 (Master Negative Prompt)

每次交付时，默认提供并微调以下集成版负面提示词（同步拦截构图均分、素描发灰、色彩脏乱差与廉价光晕）：

```text
symmetrical flat composition, uniform detail density, edge-to-edge clutter, busy foreground, scattered small gaps, competing focal points, mid-tone mud, overlapping value bands, fragmented shadows, overly bright bounce light, muddy gray shadows, dirty colors, chaotic rainbow lighting, neon color clipping, blown-out white highlights, artificial glowing halo, harsh thick black outlines, plastic skin texture, over-sharpened background
```

## 三、 Tier D 专属：MOSS-Image 像素坐标 Layout 编译规范

当总体设计路由判定为 **`Tier D: Designed_Layout`**（需精确控制图文排版、海报标题或多主体绝对位置）时，采用以下 JSON 草案结构进行空间锁定：

1. **画布尺寸**：`width` 与 `height` 必须为 16 的正整数倍（如横构图 CG 常用 `1536×1024`，竖构图海报常用 `1024×1536`）。
2. **坐标空间**：固定使用 `bbox_coord_space: "abs"` 与 `bbox_format: "xyxy"`，坐标框 `[x_min, y_min, x_max, y_max]` 以左上角 `(0,0)` 为原点。
3. **将构图法则映射为 BBox**：
   * 主体与密集建筑群映射为占比较大的主 `object`/`character` 框（遵循不对称分割）。
   * 留白区无需单独建框，但在 `summary.caption` 中显式声明留白方位，并将 `text`（标题文字）或次级焦点（如微型热气球）的 BBox 精准放置在留白区的像素坐标内，确保文字背后无高频噪点干扰。


## 四、 交付前五维终检表 (Final Director Audit)

在向用户输出最终结果前，Agent 必须逐一确认：
1. **[大型]** 缩成拇指大小后，7:2:1 的大中小体块是否依然分明？
2. **[锚点]** 第一眼视线是否落在最高对比度锚点上？锚点周围是否有干净背景圈？
3. **[分层]** 转灰度后，前（压暗遮挡）、中（受光高细节）、后（雾化低对比）三条明度带是否完全分离？
4. **[素描与节奏]** 暗部是否保持整体（无过亮反光）？画面能否一眼指出“最密处”与“最空的大块留白”？
5. **[色彩防脏]** 是否满足 60-30-10 配比？暗部是否有冷暖色相偏移？高光是否避免了死白过曝？

# 哈吉咪的二次元丝袜与腿部微观光学质感 SKILL 0.2 (零画风污染 · 全维织物光学版)

本技能是面向角色设计、设定表、精二立绘与大透视插画的**通用腿部织物光学与微观力学挂载插件（Universal Micro-Material Plugin）**。

**核心工程哲学：不教画风，只授工业级织物光学（丹尼尔数透光率、菲涅尔边缘衰减）、人体解剖挤压几何（勒肉凹陷、关节拉伸）与防脏配色彩学。**

## 零、 五大织物光学与防污染工程铁律 (Five Core Engineering Iron Laws)

### 1. 【铁律一：$100\%$ 零画风污染与“防 3D 写实胶衣/照片劫持”防火墙】 ★ 最高铁律
* **病因诊断**：
  1. **写实摄影/3D渲染劫持**：在英文 Prompt 中写入 `nylon fetish, glossy latex, raytraced skin, photorealistic stockings, Daz3D, wet look oil`，会直接触发真人腿模照片或油腻 3D 渲染权重，破坏二次元平面画风。
  2. **年代/流派词劫持**：写入 `vintage 1950s stockings, retro pin-up, gothic punk fishnet`，会污染整体画面的色彩滤镜与线稿风格。
  3. **技法越权词**：在本插件中写入 `cel-shaded, thick impasto, anime style` 会干扰用户 `Slot 6` 的主画风控制。
* **纯物理与几何转译铁律**：
  * **严禁在本技能输出中出现任何画风词、渲染引擎词、年代词或真人摄影词！**
  * 一切丝袜质感 $100\%$ 拆解为客观的**【透光率百分比 + 圆柱体中心与边缘明度差 + 织物经纬线包裹几何 + 关节褶皱疏密 + 软组织凹陷毫米数】**。画风决定权 $100\%$ 交由宿主 Skill 的 `Slot 6` 统管。

### 2. 【铁律二：圆柱体菲涅尔透射衰减律 (Fresnel Cylindrical Transmission Law)】
* **光学原理**：半透明纱线包裹圆柱形腿部时，视线垂直于腿部正中央（胫骨前侧与大腿迎光脊线），纱线孔隙正对镜头，**透肉率最高（显露底层温润肤色）**；视线移向腿部两侧外轮廓边缘（掠射角趋近 $90^\circ$），多层纱线在视觉上高度重叠，**不透明度陡增至 $85\%–98\%$（形成深色高密度外轮廓收束边）**。
* **防“平涂油漆腿”强制语法**：凡低于 $80\text{D}$ 的丝袜，严禁只写 `black/white stockings`，必须显式声明**“中心透肤暖调 $\rightarrow$ 边缘高密深色收束”**的径向衰减梯度。

### 3. 【铁律三：骨点拉伸透肤 vs. 关节屈曲堆积反差律 (Bone-Stretch vs. Flexion-Bunching)】
* **高张力拉伸区（透肉极值点）**：膝盖骨凸起处（Patella）、大腿前侧股四头肌隆起面、脚踝内外踝骨（Malleolus）及脚后跟，织物受骨骼顶撑被拉薄，透肤度比平直区高出 $25\%–35\%$，泛出明显的底层暖肤色。
* **低张力堆积区（深色闭塞点）**：膝窝后侧折痕（Popliteal crease）、脚背与小腿交界弯折处（Ankle flexion）、交叠双腿的挤压接触面，织物松弛折叠，形成高对比深色折痕线簇。

### 4. 【铁律四：丝袜防脏“底色色相偏移”铁律 (Anti-Muddy Subsurface Hue Shift)】
* **病因诊断**：黑色半透丝袜若直接与肉色做灰度混合，会产生像沾了煤灰一样的“死灰泥色（Muddy Dead-Gray）”；白色半透丝袜若不加色彩倾向，会像刷了白石膏一样死白。
* **防脏染色公式**：
  * **深色/黑色系丝袜**：中心透肉过渡区强制向**暖焦糖棕（Warm Espresso/Caramel）、深紫檀红（Deep Rosewood）或冷靛青（Cool Indigo-Slate）**偏移，严禁出现中性死灰。
  * **浅色/白色系丝袜**：中心透肉区强制透出**蜜桃暖杏肤色（Warm Peachy-Apricot Undertone）**，边缘收束区与褶皱暗部向**柔和奶白与淡薰衣草蓝灰（Milky Ivory & Lavender-Gray）**偏移。

### 5. 【铁律五：软组织咬合凹陷力学 (Anatomical Skindentation Mechanics)】
* 袜口罗纹边（Welt）、大腿环皮带（Thigh Strap）或吊带金属夹（Garter Clip）束缚大腿脂肪层时，必须产生 **$1\text{mm}–2.5\text{mm}$ 的物理包络微凹陷（Skindentation）**，使袜口上沿的自然裸肤呈现出微妙的弧形隆起过渡，严禁袜口像纸片一样平贴或悬空。

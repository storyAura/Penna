# 哈吉咪的二次元角色设定表 SKILL 0.2 修正版 (Gacha Character Sheet Compiler)

本技能是面向二次元抽卡手游、TRPG 跑团卡面与 AI 视频（Ref2VA）角色资产锁定的**工业级角色设定表与表情差分排版总控系统**。它承接 `gacha-character-concept-architect`（角色设计 Skill）与 `gacha-elite2-splash-director`（精二孤岛 Skill）的基因数据，通过 `moss-image-prompt-enhancer` 编译为像素级对齐的 **MOSS Layout JSON**。

## 零、 五大绝对工程铁律 (Five Absolute Engineering Iron Laws)

### 1. 【铁律一：$100\%$ 零画风污染与“去草图行话”原则 (Zero Style & Sketch Pollution)】
* **绝对禁令**：严禁写入 `character reference sheet`, `turnaround sketch`, `concept art draft`, `design sheet`, `blueprint`, `color palette bars`, `text annotations` 等词汇，防止激活草图线稿或乱码批注权重。
* **转译规范**：分栏排版 $100\%$ 由 MOSS `Layout JSON` 的 `bbox` 像素坐标控制；文字描述统一定义为“在纯白或中性浅灰摄影棚背景上并列陈列的多角度全完稿商业立绘阵列（A clean multi-figure array of fully finished commercial character illustrations arranged on a solid studio backdrop）”。画风词仅在 `summary.caption` 末尾填入一次。

### 2. 【铁律二：中央精二孤岛“双框嵌套 + 头脚完整入画”锁 (Dual-BBox Full-Body Island Lock)】
* **病因诊断**：单个 `character` 坐标框同时描述“精二角色 + $70\%$ 场景舞台切片”时，模型易用场景元素填满下半框，导致角色被裁切为半身像。
* **双框物理嵌套法则**（利用 MOSS Layout 支持坐标框重叠嵌套的特性）：
  1. **外层舞台框 (`label: "object"`)**：专门负责渲染 $70\%$ 的 $1:1$ 2D 孤岛舞台切片、无眼球衬底核（`B01-B04`）与边缘消融介质。
  2. **内层全身角色框 (`label: "character"`)**：嵌套在舞台框正中央，强制写入 **`COMPLETE FULL-BODY HEAD-TO-TOE AWAKENED FIGURE, crown of head, full legs, and both shoes 100% visible inside the box, zero lower-body cropping`**，锁死从头顶到鞋尖的完整全身动态。

### 3. 【铁律三：跨坐标框“双层 DNA 基因锁”人物一致性协议 (Cross-BBox Identity DNA Lock)】
* **`[Full_DNA_Lock]`（全身不可变基因串 — 注入左侧全身/三视图框与中央精二全身角色框）**：
  精确锁死：`[发色与内外双色染发 + H1前发 + H2侧发 + H3后发长度廓形 + H5呆毛 + 眼型瞳色 + 头饰物理压痕 + L2-L4 上装剪裁 + 下装裙裤 + L2袜套D数与腿环 + L3鞋靴款式]`。
* **`[Bust_DNA_Lock]`（半身不可变基因串 — $100\%$ 原样注入右侧全部 $8$ 个反应框开头）**：
  精确锁死：`[发色与内外双色染发 + H1前发 + H2侧发 + H5呆毛 + 眼型瞳色 + 头饰 + 胸口金三角核心配饰 + L2-L4 领口与肩部结构]`。

### 4. 【铁律四：画布 $16$ 倍数校准与背景底色双选开关 (Canvas $16\times$ Calibration)】
* **$16:9$ 宽屏画布（默认）**：`width: 2560, height: 1440`（$2560 = 16 \times 160, 1440 = 16 \times 90$）。
* **$21:9$ 超宽带鱼屏画布**：将 $2560 \times 1080$ 自动校准为 $16$ 的正整数倍 **`width: 2560, height: 1088`**（$1088 = 16 \times 68$）。
* **背景底色 (`Backdrop_Mode`)**：支持 `BG_GRAY (#E2E5E9 设定棚中性浅冷灰底，默认推荐，极佳衬托浅色发丝与白衣)` 与 `BG_WHITE (#FFFFFF 纯净白底)`。

### 5. 【铁律五：$2 \times 4$ 反应集“五维正交零重复”与“像素间隙硬隔离”铁律】
* 右侧 $8$ 个半身反应框严禁重复表情；每一格必须同时改变 **`[①眉型 + ②眼睑/瞳孔 + ③嘴型 + ④面部红晕/阴影 + ⑤手部入画微动作/小道具]`**，并显式声明 `waist-up bust portrait cropped cleanly at the waist`。
* 网格之间保留 $24\text{px}–32\text{px}$ 空白间距，严禁生成黑色边框线或文字气泡。

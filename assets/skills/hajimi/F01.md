# CG Art Director System (00 总体设计总控中枢)

本技能是 AI 生图领域的**主美总控中枢（Chief Art Director）**。它将用户的初步画面想法，严格按照人类视觉认知（从低频大块面到高频细节）与扩散模型去噪规律（先黑白构图、次体积素描、后色彩渲染），通过**黄金五阶流水线**转化为电影级 CG 导演蓝图与可直接粘贴的生图提示词（或像素级坐标排版 JSON）。
## 核心调度准则（严禁跳步或逆序）

Agent 在收到生图构思需求后，**必须严格按 00 $\rightarrow$ 01 $\rightarrow$ 02 $\rightarrow$ 03 $\rightarrow$ 04 的顺序执行内部推演**，并按需读取 `references/` 目录下的四个专业底座文件：

1. **第 0 阶（本文件）**：立项分析、题材档位路由（Tier A/B/C/D）与画风物理档位仲裁（2D 赛璐璐伪厚涂 vs. 3D/写实概念 CG）。
2. **第 1 阶（宏观构图与节奏）**：读取 `[references/01-composition-and-rhythm.md](references/01-composition-and-rhythm.md)`，切分 7:2:1 大中小形体、规划长短节拍与成块留白。
3. **第 2 阶（素描与黑白灰统御）**：读取 `[references/02-sketch-and-value-matrix.md](references/02-sketch-and-value-matrix.md)`，锁定三层不重叠明度带、明暗二分归并、交界线与边缘虚实。
4. **第 3 阶（色彩调配与防脏乱差）**：读取 `[references/03-color-anti-muddy-guide.md](references/03-color-anti-muddy-guide.md)`，执行 60-30-10 面积配比、冷暖极性与暗部色相偏移。
5. **第 4 阶（提示词与空间编译）**：读取 `[references/04-prompt-and-layout-compiler.md](references/04-prompt-and-layout-compiler.md)`，执行正向降噪转译、距离细节衰减与权重语序封装（或编译 MOSS-Image 像素坐标 JSON）。

## 第 0 阶：总体设计立项与动态路由表 (Master Routing)

在调用下属专业库之前，总控必须先判断以下两个维度，以裁剪不必要的工作流并防止跨模块冲突：

### 维度一：题材尺度四档路由 (Subject Scale Tiers)

| 路由档位 | 适用场景 | 01 构图策略裁剪 | 02 素描策略裁剪 | 03 色彩策略裁剪 | 04 编译交付格式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Tier A: `Environment_CG`**<br>宏大场景 / 概念设计 | 城市群落、巨物遗迹、自然奇观、科幻星港 | **全功率开启**：7:2:1 面积比 + 前景画框遮挡 + 长短建筑节拍 + 大块净空留白 + 次级焦点 | **全功率开启**：前中后三条独立明度带 + 光影二次构图 + 浓雾大气透视推远 | 大面积环境主基调（60%+）统治全局，仅在视觉锚点处释放 10% 纯度聚光灯 | 纯文本英文 Prompt |
| **Tier B: `Key_Visual`**<br>角色带环境插画 / KV | 手游宣传图、角色剧情 CG、单/双人战斗或叙事场面 | **锚点优先**：角色锁定为最高对比锚点；**强制清空角色背后的背景碎细节**（以净空/逆光雾衬托） | **极性反转**：亮背景衬深色角色剪影，或大块暗背景衬受光角色；面部与核心躯干保留最锐利硬边 | 背景主动降纯度退后；高饱和点缀色与明暗交界线卡色全部集中在角色视觉中心 | 纯文本英文 Prompt |
| **Tier C: `Standalone_Char`**<br>单人立绘 / 角色设定 | 角色全身立绘、半身肖像、纯净背景设定图 | **关闭环境三层纵深**：严禁生成建筑远景；将 7:2:1 大中小与疏密节奏内化至**披风/发量（大）、主体服饰（中）、高精密配饰（小）** | **固有色与二分优先**：强化头发、皮肤、外衣的固有色黑白灰阶梯；强调干净的明暗二分切面 | 严格在角色自身执行 60（主布料）- 30（副甲/内衬）- 10（瞳色/宝石/核心铭文）配比 | 纯文本英文 Prompt |
| **Tier D: `Designed_Layout`**<br>海报 / 多分镜 / 精确排版 | 含指定文字标题的海报、多面板漫画、严格指定物体坐标的画面 | 完成前 3 阶视觉规划后，将主体块、成块留白区与文字区映射为独立可见单元 | 确保文字所在区域的背景具备极高明度对比与极低纹理干扰（留白承载文字） | 文字颜色与主视觉锚点形成呼应或高明度反差 | **MOSS-Image Layout JSON**（含 `xyxy` 像素框） |

### 维度二：画风物理档位仲裁 (Style Physics Switch)

* **`Style_2D_Cel_SemiThick`（二次元 / 日韩手游赛璐璐 / 伪厚涂）**：
  * 仲裁指令：命令 `02 素描库` 禁用写实三大面五调子的油腻渐变，强制切换为**干净的二分光影色块（2-Tone Cel/Semi-Thick Shading） + 结构转折闭塞重色（AO Accents） + 内着色微差结构线（Colored Fine Line Art）**；命令 `03 色彩库` 在明暗交界线处加入高纯度暖色卡边（Tinted Terminator）。
* **`Style_3D_Realistic_Concept`（写实概念 CG / 电影级厚涂 / 3D 渲染）**：
  * 仲裁指令：命令 `02 素描库` 启用完整的体块转折明暗交界线、大气光学景深（DoF）与消亡边（Lost Edges）；命令 `03 色彩库` 强调物理材质反射、冷暖环境天光漫反射与胶片级动态范围。

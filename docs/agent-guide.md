# Penna 使用指南(供 AI 助手使用)

> 使用方法:把这份文档整个发给任意 AI 助手,再告诉它你想做什么,让它带你找到对应的功能、一步步设置好。

本文对应 Penna v1.0.3。

---

## 给 AI 助手的说明

你将协助用户使用 **Penna 羽毛笔**。请遵守以下规则:

1. **按本文的名称指路。** 下文用「」标出的都是界面上的文字(简体中文界面)。用户界面是别的语言时,按位置描述,不要编造译名。
2. **API Key 只由用户本人填进 Penna。** 不要让用户把 Key 发到对话里;如果用户发了,提醒他到服务商后台作废这个 Key 并重新生成。
3. **配置模型接口时,以 [API 配置指南](api-setup.md) 为准。** 用户手上没有那份文档时,请他一并发来。
4. **先弄清用户要做什么,再给步骤。** 一次给一步,等用户确认后再说下一步。
5. **不要编造功能。** 本文没写的按钮或设置,直接告诉用户你不确定,请他描述或截图界面上看到的内容。
6. 用户的界面和本文对不上时,先请他到「设置 → 软件设置 → 版本与更新」核对版本。

---

## 软件是什么

Penna 是 Windows 与 Linux 桌面端的文生图提示词工作台,帮用户撰写、修改、润色和翻译**正面提示词**。

- Penna 产出的是提示词或 MOSS-Image 布局 JSON,复制到绘图工具使用;也可以接入 ComfyUI 作为出图后端,在「最终提示词」上直接出图。
- Penna 只处理正面提示词,负面提示词由用户在绘图工具里自行填写。
- Agent 对话需要用户自备模型接口(在线服务或本机程序)。本地反推的 Tag 反推、标签与角色查询可以离线使用。
- 核心规则:Agent 和润色的结果先以**待确认改动**显示,用户采纳后才写入成稿。成稿为空时新内容直接填入;打开「自动审批」后改动自动采纳。

## 软件和数据在哪

**下载**:<https://github.com/storyAura/Penna/releases>

| 系统 | 文件 | 运行方式 |
| --- | --- | --- |
| Windows 10 / 11 | `Penna-v<版本>-windows-x64.zip` | 解压到任意文件夹,运行 `penna.exe` |
| Linux | `Penna-v<版本>-linux-x86_64.AppImage` | `chmod +x` 后直接运行 |

**用户数据**保存在「文档\Penna」(Linux 上为 `~/Documents/Penna`),和程序分开存放,更新程序不影响它。

| 文件或文件夹 | 内容 |
| --- | --- |
| `config.json` | 设置(不含 Key) |
| `keys.dat` | API Key 等机密,经 Windows DPAPI 加密;Linux 上存入系统钥匙串 |
| `workspace.json`、`attachments\` | 工作台的成稿、对话、历史提示词,以及对话附件 |
| `archive.json`、`archive\` | 档案库及预览图 |
| `images\` | ComfyUI 生成的图片,位置可在「设置 → ComfyUI」更换 |
| `characters.json`、`character_favorites.json`、`characters\` | 自己的角色、收藏及图片 |
| `layout.json` | 区域控制工作台 |
| `notebooks.json` | 记事本 |
| `local.json`、`models\`、`runtime\` | 本地反推的设置、下载的模型、llama.cpp 运行时 |
| `skills\` | 导入的 Skill |
| `error.log` | 错误日志,其中的 Key 已被替换为 `***`,可用于排查问题 |

备份时复制整个文件夹即可。`keys.dat` 只有原电脑的当前用户能解开,换电脑后要重新填写 Key。

## 界面在哪

窗口最左侧是图标栏,从上到下七页,切换时输入的内容保留:

| 页面 | 用途 |
| --- | --- |
| 「工作台」 | 写提示词的主页面 |
| 「档案库」 | 手动保存的成稿与布局 |
| 「角色库」 | 内置角色与自己的角色 |
| 「本地反推」 | 把图片反推成标签或提示词 |
| 「区域控制工作台」 | 框选区域,生成 MOSS-Image 布局 JSON |
| 「记事本」 | 随手记录,输入即保存 |
| 「设置」(最下方的齿轮) | 全部设置,见「怎么设置」一节 |

**「工作台」的布局**

- 左栏是「工作区」,上半是「成稿正文」和页签,顶栏有「润色」「翻译」「固定」「合并」「展开 / 收起」「保存」「清空」。
- 左栏下半是「成稿汇总」(Danbooru 风格 Tag 汇总)、「最终提示词」和「历史提示词」。**交给绘图工具的是「最终提示词」**,点「一键复制」取走;接入 ComfyUI 后点卡片上的「出图」直接生成,图片显示在卡片下方。
- 右栏是 Agent 对话,顶栏选模型和 Preset,另有「新对话」。
- 窗口最右侧是一列侧栏图标:ComfyUI、历史对话、穿甲弹开关(闪电图标),点开的面板半透明地盖在对话上。
- 输入框上方是快捷操作和「副聊天」;输入框左下角切换「手动审批 / 自动审批」,旁边的「思考强度」按钮点开浮出卡片,拖滑块调强度(较低、中等、较高、极高),默认中等。
- 用户消息下面的笔图标:编辑后重新发送,后面的对话会被替换,可在操作记录里回到编辑之前。最后一条回复下面的「重新回复」再写一份,`‹ 2/3 ›` 翻看之前的几份,翻到旧回复不改动成稿,要用其中的成稿就点卡片上的按钮。
- 最左边的窄条是「操作记录」,点开后可以回到任意一步之前或之后。

## 首次使用

1. 打开「设置 → API 管理」,点「常用服务」选一家或「添加模型」,按 [API 配置指南](api-setup.md) 填好。
2. 依次点「拉取模型」「测试连接」「保存」。
3. 回到「工作台」,在右栏输入想要的画面,例如「雨夜街角,一个撑伞的少女」。
4. Agent 可能先提几个问题,点选项回答;之后成稿出现在左栏。
5. 看红绿对比,点「采纳」或「驳回」;满意后到「最终提示词」点「一键复制」。

## 能做什么、怎么用

### 写提示词

直接在右栏对 Agent 说要求。成稿按【主体】【光影】这样的标注分段,每段有自己的操作按钮。

| 想做的事 | 做法 |
| --- | --- |
| 只改某一段 | 点这一段的讨论按钮,再说要求;或点这一段的润色按钮 |
| 改一小截文字 | 在成稿里选中,右键选「润色选中的」或「翻译选中的」 |
| 保护某些内容 | 选中后点「固定」,固定区对润色和 Agent 都是只读的 |
| 调整段落 | 拖动段左上角的把手;右键标注可以改名 |
| 去掉分段 | 点「合并」,整页变成一段连续文字 |
| 改回之前的版本 | 用「操作记录」,或在「历史提示词」点「放回成稿」 |
| 重复说的话 | 在「设置 → 快捷操作」加一个按钮 |
| 引用写法说明 | 在输入框输入 `@` 选择 Skill |
| 看上下文用量 | 发送键左边的小圆环。悬停弹出面板:分色圆环和系统预设、Skill、内置规则、成稿、对话、工具结果、附件的占比,再加输入、缓存、输出和当前的 API、模型。切到历史对话时显示「预计加载」 |
| 发参考图或文件 | 用按钮、拖放、Ctrl+V 或右键「粘贴」;图片最大 10 MB,模型要支持看图 |

### 分页与系列

每页是一条独立的提示词,页可以归入系列,用「成稿正文」旁的页签切换。同一系列共用一场对话,Agent 能参照系列内的其他页;不同系列互不相通。系列最多 20 个,每个系列页数不限。

可以直接让 Agent 写一组,例如「按这个故事写 4 个分镜,每镜一页」。双击页签或系列名可以改名,右键有更多操作。

### 副聊天

点快捷操作一栏右侧的「副聊天」,打开半透明浮窗,另开一场对话。它有单独的模型和穿甲弹开关,能读取工作区,写出的成稿同样放进工作区。适合一边写一边问问题、换一个模型提意见。

### 本地反推

打开「本地反推」,把图片拖到左边(也可以点「从剪贴板粘贴」或按 Ctrl+V),再选一种方式:

| 标签页 | 用途 | 准备工作 |
| --- | --- | --- |
| 「Tag 反推」 | 用 ONNX 模型生成 Danbooru 标签 | 选模型,首次使用时下载 |
| 「NL 反推」 | 用看图模型写自然语言描述 | 下载模型;GGUF 模型还要 llama.cpp 运行时,点「启动」后再点「生成」 |
| 「LLM 反推」 | 用 API 管理里的模型反推,最多两个并排比较 | 模型要支持看图 |

结果可以复制、「发送给 Agent」或「放到成稿」。也可以直接对 Agent 说「用 Tag 反推这张图」。

已经下载过模型时,不必重新下载:到「设置 → 本地反推」的「模型文件夹」添加所在文件夹。

### 区域控制工作台

在画布上框出区域并逐块描述,生成 MOSS-Image 布局 JSON;右侧有独立的布局对话,可以让 Agent 排好。形状工具、透视辅助、「3D 视图」、打光预设和「光影预览」都在这一页。在「工作台」对 Agent 说「转成 JSON」或「按位置排版」时,任务会自动转到这里。

点「保存」存入档案库的「区域控制」分区,从档案库可以「复制 JSON」或「放到区域控制工作台」。

### 漫画

在区域控制工作台对 Agent 描述漫画内容,它按「漫画分格」Skill 规划分格。在画布上手画好的分格原样保留,Agent 逐格补全。同一系列的角色卡保证角色特征跨格、跨页一致。

### 角色库

- 「内置」:约 7.4 万个 Danbooru 角色,可按英文名、中日文译名或作品名搜索;外貌和服装分开,可单独取用;变身、换装后的形态一并列出。
- 「全部」:同时检索自己的角色和内置角色。
- 「我的」:自己的角色,可保存别名、简介、提示词、图片和多套服装。
- 「收藏」:收藏的内置系列和角色。

对话里提到角色名,程序会预先查好特征词交给 Agent;也可以说「把这个角色存进角色库」。

### 档案库与记事本

- 「档案库」保存手动存下的内容,分成稿和「区域控制」两个分区。在工作台点「保存」存当前页,点「保存系列」存整个系列。用 ComfyUI 出过图时,保存会自动用最新的图做预览图。
- 「记事本」和 Agent 不互通,适合存常用片段。

## 怎么设置

「设置」左边有十个分区。

### API 管理

卡片协议选「Grok 账号」时不填 Key,点「登录 Grok」在浏览器里确认。顶部「联网搜索」一行选「不联网」「自动」或指定接口;只列出带搜索工具的接口(Gemini、Grok、OpenAI、智谱、百炼、OpenRouter)。

配置模型接口,详见 [API 配置指南](api-setup.md)。顶部「Agent 对话」「润色」两行指定各自优先用哪个接口;列表顺序就是后备顺序。接口卡片的改动点「保存」后才生效。

### 翻译

勾选要用的引擎并拖动排序,失败时自动换下一个。

| 引擎 | 需要填写 |
| --- | --- |
| Google 网页接口、MyMemory | 免费,无需填写 |
| Google Cloud | API Key |
| 阿里翻译 | AccessKey ID、AccessKey Secret |
| 百度翻译 | APP ID、密钥 |

还可以设置每个引擎的尝试次数、单次超时,以及是否启用「LLM 意译」。英文界面没有翻译按钮。

### Preset

Preset 决定 Agent 的写作风格。内置「MOSS 视觉」「动漫风格」「真实风格」,新安装默认是「MOSS 视觉」(先构思画面里正在发生的事,再定构图,写成连贯的英文描述)。旧版内置的「协同写词」「反推润色」「意译合稿」「自由改稿」升级时去掉,改过的保留。可以「新建 Preset(复制当前)」后修改系统提示;对话顶栏可以随时切换。

页面最下面是「穿甲弹」:一段接在所有系统提示最前面的话,默认关闭,内容自己填,可以导入、导出 `.txt`,点「保存」后生效。

### Skills

Skill 是写法说明,决定 Agent 按什么方式做事。内置 10 个。写提示词、画面规划、角色库是核心,排在最前,正文常驻,不能关闭。其余默认开启,可逐个开关:写 Skill、转标签、照图写、区域控制、漫画分格、哈吉咪主美(主美知识库,含连续分镜)、本地反推(这些由 Agent 用到时加载,也可以在输入框用 `@` 点名;核心的三个常驻,不在 `@` 列表里)。用到的 Skill 会列在回复上方「已使用技能」。画面没讲细时,「画面规划」先给一张问卷:每项默认选中推荐的选项,改好点「确定」一次交回;某项再点一下已选的,就交给 Agent 定。局部修改、同题变体、意译都归「写提示词」,整理反推归「照图写」。

- 「添加 Skill」:拖入 `.md` / `.zip`,或直接填写名称、简介和正文。`.zip` 里与 `SKILL.md` 同一文件夹的 `.md` / `.txt` 是模块,Agent 写 `技能名/文件名` 按需加载;适合把大型知识库做成一篇目录加若干模块。
- 不想让 Agent 先提问时,在要求里说「直接写」。
- 也可以在对话里让 Agent 写一个新的 Skill。

### 参数与工具

按 Preset 设置「温度」和「Top P」。两者都影响随机程度,一般只调一个:想要稳定就调低,想要变化就调高。

此页的「工具」清单是预留项,勾选与否目前不影响 Agent。

### MCP

顶部是内置的 Danbooru 在线标签搜索开关,关掉后只查本机词库。「添加服务」可以添加远程地址或本机命令的 MCP 服务,并测试连接、列出工具。

目前 Agent 对话还不会调用用户添加的 MCP 工具。

### ComfyUI

把 ComfyUI 当作出图后端,不需要在 ComfyUI 里装插件。

1. 先启动 ComfyUI。本机默认地址是 `http://127.0.0.1:8188`;还有云端的 ComfyUI 时点「添加 ComfyUI」,填它的名称、地址,有鉴权时填「Key」,再点「设为当前」。
2. 点「测试连接」,显示「已连接 · ComfyUI 版本 · 延迟 ms」即可。
3. 没导入工作流时用内置的文生图,模型是 ComfyUI 里的第一个。要用自己的工作流:在 ComfyUI 里打开它,菜单选「导出 (API)」(旧版要先在设置里开启开发者模式),再点「导入 (API)」选中这个 JSON。可以导入多个,点一个设为当前,或在侧栏里切换。普通保存的 JSON 不能用。
4. 窗口最右侧侧栏的第一个图标是 ComfyUI(工作台和区域控制工作台都有),圆点绿色表示已连接。点开可以看连接延迟,下拉切换 ComfyUI 和工作流,开关 LoRA、改权重、添加或去掉 LoRA,改动直接存进工作流。「LoRA 配置」下拉里选「新建」保存当前的 LoRA 组合,之后点一套就切换过去。
5. 在对话或副聊天里说「出一张图」「画出来看看」,Agent 会自动出图,进度和图片显示在那条回复下面;Agent 看不到图,效果要用户自己判断。说「换成某某模型」时,Agent 换成用这个模型的工作流;没有这样的工作流时会先问。
6. 导入后出图时提示「找不到正面提示词框」:在正面提示词框里写上 `{{prompt}}`,重新「导出 (API)」并导入。
7. 「图片位置」默认是「文档\Penna\images」。「更换位置」会把已有的图一起搬过去,「打开」在文件管理器里打开文件夹。

### 快捷操作

管理输入框上方的按钮,每个按钮由名称和一段文字组成,点击后把文字接在输入框末尾。默认有「转成自然语言」「转成 Tag」。

### 本地反推

| 设置 | 说明 |
| --- | --- |
| 「模型文件夹」 | 添加已有模型所在的文件夹,子文件夹一起查找;HuggingFace 与 ModelScope 的缓存文件夹标「自动」 |
| 下载来源 | 「官方源」「HuggingFace 加速」「ModelScope」「自定义」,下载失败时自动换用其他来源 |
| HuggingFace Token | 下载需要申请访问的模型时才填 |
| 「llama.cpp 运行时」 | Windows 上可一键下载,可选「官方源」或「GitHub 加速」;Linux 上自行下载后,用选择按钮指定 `llama-server` |
| 「llama-server 参数」 | 「GPU 层数(-1 全部)」「上下文长度」「端口」(默认 8091) |
| 「看图描述的要求」 | NL 反推的写作要求,可保存多条并切换 |

连不上 HuggingFace 时,建议把下载来源改为「ModelScope」。显存不够时,调低 GPU 层数或换小一点的量化档。

### 软件设置

| 设置 | 说明 |
| --- | --- |
| 「界面语言」 | 简体中文、繁體中文、English、日本語,同时决定成稿对照译文的语言 |
| 「深色模式」 | 「跟随系统」(新安装的默认)、「始终开启」、「始终关闭」、「自定义时间段」;时间段填开始和结束,如 19:00 到 07:00,结束早于开始表示跨午夜 |
| 「界面大小」 | 1 到 2 倍 |
| 字体与头像 | 英文字体、中文字体可填任意已安装的字体;Agent 和用户的头像可换成自己的图片 |
| 「压缩大图」 | 超过 1 MB 的图片缩到 2048 像素以内并转为 WebP,默认开 |
| 「自动审批」 | 打开后成稿的改动直接采纳,默认关 |
| 「分辨率对齐」 | 区域控制画布的宽高取它的倍数,默认 16,填 1 为不对齐 |
| 「版本与更新」 | 选「正式版」或「测试版」通道,点「检查更新」;发现新版本后点「更新并重启」 |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 对话顶栏显示「未连接模型 · 去设置」 | 到「设置 → API 管理」添加并启用一个接口 |
| 模型接口报错 | 对照 [API 配置指南](api-setup.md) 的「常见报错」 |
| Agent 不回应图片 | 当前模型可能不支持看图,换一个多模态模型 |
| 成稿不能编辑 | 有待确认改动时成稿只读,先「采纳」或「驳回」 |
| 成稿里的内容改不动 | 固定区是只读的,先取消固定 |
| Agent 总是先提问 | 在要求里说「直接写」,或把画面写详细 |
| 联网搜索很久没结果 | 一次搜索最多等 90 秒,超时会在回复上标「联网搜索失败」;可到「设置 → API 管理」的「联网搜索」换一个接口 |
| Agent 说不能联网 | 到「设置 → API 管理」的「联网搜索」选「自动」,并启用一个带搜索工具的接口 |
| `这个 Grok 账号没有 API 权限` | 账号订阅没有 API 权限,升级订阅,或改用 xAI 的 API Key |
| 模型下载慢或失败 | 在「设置 → 本地反推」更换下载来源,再点一次下载可接着下 |
| 出图时「连不上 ComfyUI」 | 确认 ComfyUI 已启动,「设置 → ComfyUI」里的地址和它窗口里显示的一致 |
| 出图时「ComfyUI 返回 400」 | 工作流里的模型名在这台 ComfyUI 上不存在,在 ComfyUI 里改好后重新导出、导入 |
| 「系列满了」的红色提示 | 系列已达 20 个,删掉不用的系列 |
| 程序报错或行为异常 | 查看「文档\Penna\error.log」,把相关内容发到 <https://github.com/storyAura/Penna/issues> |
